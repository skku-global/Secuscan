# These four were imported but never declared: they were installed by hand on the
# development machine, so everything worked here and nothing worked on a fresh
# checkout. The failure is an ImportError at startup, which names the module but
# not the reason it is absent - so the rule is that a direct `import` of a
# third-party package earns a line in this file at the same time, not later.
python-dotenv>=1.0      # config.py imports this at module scope to read backend/.env.
                        # Nothing starts without it, and a .env file on disk does
                        # nothing at all until something loads it - see config.py.
google-auth>=2.57       # Google's own ID-token verifier. NOT a general JWT library:
                        # google_auth.py leans on it to fetch Google's public keys and
                        # check the signature, which is the step that separates
                        # "the token says" from "Google says".
pyotp>=2.9              # RFC 6238 TOTP, for two-factor sign-in.
segno>=1.6              # QR rendering for TOTP enrolment, done in-process so the
                        # shared secret never leaves this server. See the import
                        # comments in auth.py for why segno over `qrcode`.
